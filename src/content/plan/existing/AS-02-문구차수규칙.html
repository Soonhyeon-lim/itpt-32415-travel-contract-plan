AS-02

문구 · 차수 규칙

AS-01의 각 교부 시점에 어떤 문구가 나가고, 차수가 어떻게 매겨지는가.

발송 유형 별, 여행계약서 상단 문구 (3개 유형)

유형트리거 · 차수계약서 상단 문구
1차 (최초)자동 · OK/OK 다음날
seq1		[1차 여행계약서] 본 계약서는 예정 일정 기준으로 작성되었으며, 출발 2일 전에 확정된 일정이 반영된 계약서를 다시 발송드립니다.
D-2 최종 확정자동 · D-2 항상
차수 +1 (사유=출발 확정 안내)		[N차 여행계약서] 출발을 앞두고 확정된 일정이 반영된 계약서입니다. 이후 예약 내용이 변경되는 경우에는 변경 사항이 반영된 계약서를 다시 보내드립니다.
N차 재교부수동 · 요건 발생 시
차수 +1		[N차 여행계약서] 예약 내용이 변경되어 계약서를 다시 보내드립니다. 변경된 항목은 [변경 내역] 탭에서 확인해 주세요.

문구 분기 규칙

  • 차수 번호(N차 여행계약서) = trvlCndmSeq (계약서 변경 순번)
  • 유형 구분 = 사유 값(“출발 확정” vs 변경) — 판별용 내부 값일 뿐, 고객 문구에는 노출하지 않음

변경 내용 표기 규칙 2026-07-20 변경

  • 상단 문구에는 변경 사유를 나열하지 않음 — [변경 내역] 탭으로 유도만.
  • 실제 변경 항목은 변경 내역 표에서 전 건 확인(항목 / 이전 내용 / 변경 내용).
  • 대표 사유 1건 + “외 N건” 요약 폐기 — 요약 대신 전 건을 표로 보여주는 방식으로 전환(개선 ①).

차수 정의 · 동의

  • 차수 = 계약서 판(版) 번호 — ① 계약 내용 변경 시 ② D-2 최종 확정 시 +1. D-2 당일 변경 겹침 시 +1은 1회만(사유=변경 사유).
  • 동의 = 차수 단위 현행 그대로(D-2 갱신 차수 = 최종본 기준 동의 확보).
  • 알림톡 = 현행 양식 그대로(N차·사유 미명시, MAP 변수 신규 불요). 발송 채널(알림톡·이메일·SMS)은 기존 교부 채널 정책 그대로.
