① 계약서 차수 · 발송 유형별 안내

  • 상단 문구: [N차 여행계약서]와 최초 / 출발 확정 / 변경 재교부 안내를 표시한다.
  • 고객 Front: 차수·이전 완료본·변경 유무와 무관하게 계약서만 표시. 변경내역 탭·비교표·탭 안내는 미노출한다.
  • 하나허브: 완료 스냅샷 비교와 변경내역 조회를 유지한다. 교부완료 시 스냅샷 저장 기준도 유지한다.

② Front 여행경비 5개 항목 · 개인추가경비 합산

QCH만 별도 · TAX는 개인 추가 경비에 포함

유류할증료(QCH)만 제외한 22개 변동항목을 합산한다. 하나허브는 이전·현재 합계를 표시하고 고객 계약서는 해당 교부본 금액을 표시한다.

  • 합계 검증: 총 N인 경비총액 = 예약 내 각 여행자의 1인 여행경비 합계. 할인·음수도 포함한다.
  • 1인 여행경비는 상품가 + 유류할증료 + 개인추가경비를 포함한 총액. 상세 금액을 총액에 다시 더하지 않는다.
  • 개인추가경비 대상 0건이면 해당 줄 미노출, 대상이 있으면 0원도 표시. 하나허브 이전·현재 합계 표기는 유지.

③ 일정표 선택관광 · 쇼핑 단순 표기

선택관광·쇼핑을 교통·숙박·식사와 같은 일정표 표시 방식으로 안내한다. 닷컴 Vue·하나허브 OZ Report에 반영한다. 상품가 추가는 Front 기준이며 OZ는 기존 범위를 유지한다.

⑤ 여행계약서 조회 진입 페이지 검토 필요

비회원 예약조회 페이지를 재사용하여 여행계약서 진입 시 타이틀을 “여행계약서 조회”로 바꾸고 패키지 탭만 표시한다. 예약번호 자동 채움을 유지하고, 조회 성공 후 예약 상세로 이동한다. 계약서 팝업은 예약 상세에서 표시한다.
