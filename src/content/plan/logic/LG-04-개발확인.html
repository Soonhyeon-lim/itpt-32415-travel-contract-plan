LG-04

개발 확인

PPT 25p와 동일한 확인사항. 기획 기준과 구분하며 실제 구현이 확인된 내용은 아닙니다.

[개발 확인] 완료·복구

  • 세 경로의 완료 이벤트·공통 로직 확인
  • 발송 요청/접수/성공 중 완료 판정
  • 실패·SMS/MMS 대체·재시도·중복 처리
  • 상태 전환과 저장의 일관성·복구
  • 예약·여행자·차수·교부 경로 연결

[개발 확인] 원천·보존

  • 발송 당시 버전과 후속 열람값 일치
  • 22개 금액 원천·통화·무항목/0원 구분
  • 보험 경비명·약관 원문/버전 확보
  • 이름·연락처 판별용 저장·보관·접근

[개발 확인] 상태·차수

  • 이전 완료본 선택·미열람 완료본 포함
  • 배포 전 기교부·스냅샷 없음 응답
  • 열람 여부·시각 기록/화면 제공 범위
  • 허브 선택 차수 / 누적 이력 범위
  • D-2 차수 +1·복수 채널 중복 방지
  • 고객 비교 데이터 미사용·응답 분리
  • 관리자 조회 권한·접근 범위 확인

항목별 추가 확인 사항도 함께 확인한다.
