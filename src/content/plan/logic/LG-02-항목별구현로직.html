LG-02

항목별 구현 로직

「개선 항목」IM-04의 ①~⑤와 같은 번호 — 각 항목을 무엇으로 구현하는가.

① 계약서 차수·변경 내역 표기 닷컴 Vue

  • 데이터 — 차수 = trvlCndmSeq(계약서 변경 순번, 확인 완료) / 변경 내역 = LG-01에서 BE가 교부 시점에 비교·저장한 결과를 API로 수신(API에 변경 내역 필드 추가 선행 필요). FE는 비교하지 않고 렌더만.
  • 상단 문구 분기 LG-01 화면 활용 (2) — 「기존 로직 점검」AS-02 발송 유형 매트릭스 3유형. 유형 구분은 사유 값으로 판별(“출발 확정” vs 변경) — 판별용 내부 값일 뿐 문구에 노출하지 않음.
  • 첫 발송·재교부 문구 — 직전 교부 이력이 없는 첫 발송(seq≥2)은 “다시”를 제외한 1차형 문구 / 재교부 유형은 고정 유도 문구(“변경된 항목은 [변경 내역] 탭에서 확인해 주세요”) — 항목명·사유 미포함.
  • 변경 내역 탭 렌더 LG-01 화면 활용 (1) — LG-01 비교 결과 배열을 그대로 표로 렌더(No / 변경 항목 / 이전 내용 / 변경 내용). 요약·생략 없이 전 항목 표기 — 별도 집계·가공 없음.
  • 노출 조건 — 비교 결과 건수 > 0 일 때만 탭 UI 생성 → 0건이면 탭 자체를 렌더하지 않고 현행 단일 화면 유지(기존 UI 회귀 없음).

⚠ 항목명 표시 규칙 확정 필요 — 비교 결과는 내부 필드 단위로 나오므로, 고객 노출용 항목명 매핑(예: 상품명·여행기간·개인추가경비)과 노출 제외 필드(내부 관리값 등) 정의가 필요.

하나허브 OZ 문서는 미변경 — 상담용 사유는 교부내역 메뉴에서 확인.

② 개인추가경비 합산 한 줄 닷컴 Vue

  • 계산 — 상품가 외 변동 항목 전체 합산(항공·호텔·지상·기타 + 매출할인 마이너스 포함) → Σ전 인원(상품가 + 개인추가경비) = 총 N인 경비 총액 산술 일치 보장(예약코드 전 인원 합 기준). 음수 허용.
  • 노출 조건 — 변동 항목 건수 > 0(금액 기준 아님) → 0건이면 미노출, 1건 이상이면 합산 0원이어도 0원 노출.

⚠ 집계 소스 미확정 — 계약서 API의 flxb*는 금액 없는 Y/N 체크 플래그(분석정리 6.6). 합산 소스를 계약서 API 확장으로 갈지 결제·예약 API 병행 호출로 갈지 확인 필요 → LG-04 개발 확인 1번(최우선).

③ 일정표 선택관광·쇼핑 단순 표기 닷컴 Vue

일정표 영역에 작은 양식 추가 — 교통·숙박·식사와 동일한 “일정표 표시” 방식. 상세 미표기라 데이터 요구가 크지 않음.

④ 하나허브 여행계약서 교부내역 — 합산값 · 변경 내역 하나허브

  • 구현 제약 (1) 합산값 — ②와 합산 로직을 반드시 공유해야 함.
  • 구현 제약 (2) 변경 내역 팝업 — LG-01에서 BE가 저장해둔 같은 변경 내역 필드를 조회해 렌더. 표 구성(No / 변경 항목 / 이전 내용 / 변경 내용)·항목명 매핑·노출 제외 규칙 전부 동일 적용 — 하나허브에서 다시 비교하지 않음(비교는 BE 1회, 화면은 렌더만).
  • 노출 조건 — 고객 화면과 동일하게 비교 결과 0건이면 팝업 진입점 미노출.

하나허브 OZ 문서 양식은 미변경 — 여행계약서 교부내역 메뉴에만 표시 추가.

⑤ 여행계약서 조회 진입 페이지 검토 필요

  • To-Be(현 안) — 기존 비회원 예약조회 페이지를 그대로 재사용하되 진입 컨텍스트(redirectUri)를 읽어 타이틀·상품 탭을 동적 전환. 페이지 카피가 아님 — 로직 이원화 시 divergence 리스크(분석정리 7.8) 회피가 설계 의도.
  • 승계 4조건 — ① 예약코드 자동주입 유지(이름+휴대폰만, 세션 만료 경로 포함) ② 딥링크 컨텍스트로 타이틀 + 패키지 탭 단독 분기(호텔·항공 탭 미노출) ③ 조회 성공 → 예약 상세로 이동(계약서 팝업은 예약 상세에서 노출 — 현행 흐름 유지) ④ 비회원 전용(회원은 로그인 → 마이페이지).

⚠ 개발팀 검토 필요 — 컨텍스트로 타이틀만 바꾸는 방식보다 여행계약서 전용 진입 페이지(정적 shell)를 따로 두는 편이 구현 효율적일 수 있음. 착수 전 협의 대상.

로그인 페이지 하단 ‘비회원 예약조회’ 버튼 라벨은 공용이라 미변경(보류).
