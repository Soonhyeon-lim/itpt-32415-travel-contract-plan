#시스템변경 내용규모
①여행계약서 API · BE 비교 로직변경 내역(비교 결과) 필드 추가 — 교부 시점에 BE가 N차·N-1차를 비교·저장, API는 저장된 배열을 응답
N-1차 원본을 내리는 것이 아님 · 닷컴·하나허브·파트너포탈이 같은 필드 공유(LG-01)		중
①닷컴 Vue 계약서 팝업상단 문구 블록 — seq·사유·교부이력 분기소
①닷컴 Vue 계약서 팝업변경 내역 탭 신설 — 비교 결과 표 렌더(4열) · 0건이면 탭 미생성소~중
②닷컴 Vue 계약서 팝업개인추가경비 합산 줄 (변동항목 전체 + 매출할인, 0건일 때만 미노출)소
③닷컴 Vue 일정표선택관광·쇼핑 단순 표기소
④하나허브 여행계약서 교부내역
+ 파트너포탈(화면·API 공유)		개인추가경비 동일 합산값 표시 (②와 로직 공유) + 변경 내역 팝업(①의 변경 내역 탭 재사용, 0건이면 진입점 미노출)
파트너포탈은 같은 화면·API를 쓰므로 추가 구현 없이 동일 반영 — 노출 화면만 1곳 더		소~중
⑤닷컴 웹 조회 페이지여행계약서 딥링크 진입 시 타이틀 동적 전환 + 패키지 탭 단독 노출 (페이지 재사용)소
확인배치 (TMS)닷컴 직접예약 D-2 발송 포함 (현행 확인 후)확인/소
