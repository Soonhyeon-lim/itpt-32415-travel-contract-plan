변경 내역 팝업 개선 ⑤

차수별 [보기] 클릭 → 팝업으로 변경 내역 표 확인. 표 구성은 고객 화면과 동일(No / 변경 항목 / 이전 내용 / 변경 내용).

왼쪽 화면 VIEW의 보기 3을 클릭하면 실제로 팝업이 열립니다 — 동작 확인용 목업.

고객 화면(SC-02 ②)의 변경 내역 탭을 그대로 사용 — 같은 LG-01 비교 결과·같은 항목명 매핑. 하나허브용 별도 구현 아님.

변경점 0건인 차수는 진입점 미노출(예: 최초 교부 1차).

버튼은 [보기 N]으로 변경 건수 포함 표기(확정) — 목록에서 차수별 변경 규모를 한눈에 대조하는 용도. 고객 화면 탭 라벨(건수 미표기)과 다른 것은 의도된 차이.

3
재교부 사유 (현행 유지)

재교부 사유는 현행 하나허브 값을 그대로 표시 → 상담 응대 근거.

변경 내역(②)과는 별개 데이터 — 사유는 기존 값, 변경 내역은 신규 비교 결과. 이번 개편으로 사유 생성 방식은 바꾸지 않음.

⚠️ 실화면 실사(2026-07-21): 교부내역 그리드에 재교부 사유 컬럼이 없음 — 사유 값의 소재(발송통계 탭·타 화면·DB 전용) 확인 필요. 이 화면에 노출하려면 사유 컬럼도 신설 대상이 될 수 있음 → 개발 확인 항목.

기존 컬럼·상태 (현행)

기존 컬럼(순번·고객동의·계약형태·교부일시 등)은 현행 그대로. 하나허브 OZ 문서(계약서 양식) 자체는 미변경 — 이 화면에 표시 항목만 추가(개인추가경비·변경 내역).

실화면에 별도 차수 컬럼은 없고 순번(교부 이력 순번)이 그 역할 — 정책의 "차수" 개념과 이 화면 순번의 매핑은 LG-01 저장 구조 확정 시 함께 정리.

파트너포탈도 동일 적용 — 추가 구현 없이 같은 항목 노출(「개선 로직」LG-03).
