변경 내역 탭 개선 ②

조건부 노출 — 직전 차수 대비 변경점이 있을 때만 [계약서 / 변경 내역] 탭이 생기고, 변경점이 없으면 탭 없이 현행 UI 그대로. 탭 라벨에 건수는 표시 X

표 구성 = No / 변경 항목 / 이전 내용 / 변경 내용 4열. 이전 값은 회색, 변경 값은 브랜드 컬러로 대비

상단 문구(유도) → 변경 내역 탭(전 건)의 2단 구성 — “왜 또 왔나”는 문구로, “무엇이 바뀌었나”는 표에서만 확인.

표 데이터 = 「개선 로직」LG-01 N차·N-1차 비교 결과를 요약 없이 전 건 그대로 렌더 (별도 집계 없음).

3
개인추가경비 합산 금액 개선 ③

1. 총 N인 경비총액 N원

예약코드 기준, 모든 인원 N명 표기

예약코드 기준, 모든 인원 각각 [상품가 및 변동 금액] 전체 합산 금액 노출

2. 1인 여행경비 N원

예약을 조회한 여행자 순번 1인에 대한 여행경비(순매출액 = 판매상품가 + 변동가) 노출 → 즉 여행자 1인 기준 총액

3. 개인추가경비 N원

예약을 조회한 여행자 순번 1인에 대한 변동금액 노출(변동금액 Only)

음수 허용(할인만 있을 때) · 노출 조건은 금액이 아니라 건수 — 변동 항목 0건이면 미노출, 1건 이상이면 합산 0원이어도 개인추가경비 0원 노출(선택관광+매출할인 상계 케이스) · 세부명·건수 미노출.

4
일정표 선택관광·쇼핑 표기 개선 ④

일정표에 선택관광·쇼핑을 단순 표기(상세 미표기) — 교통·숙박·식사와 같은 "일정표 표시" 방식.

5
약관 동의 영역 (현행 유지)

전체 약관 동의 체크 + 표준/특별약관 동의 라디오 + 개인정보 수집·이용 동의. 동의는 차수 단위(D-2 갱신 차수 = 최종본 기준).
