2
고객 변경내역 미노출 [v1.4]

차수·이전 완료본·변경 유무와 무관하게 계약서만 표시

계약서 / 변경내역 탭 바 및 비교표 미노출

고객에게 변경 0건·비교 대상 없음 안내도 제공하지 않음

계약서 본문·차수·발송 유형별 안내·약관 동의 유지

BE 스냅샷 저장 및 하나허브 변경내역 조회 유지

-
상단 차수 문구 – 1차(최초)

조건 : 자동 발송, 항공/지상 OK, 다음날 발송

문구 : [1차 여행계약서] 본 계약서는 예정 일정 기준으로 작성되었으며, 출발 2일 전에 확정된 일정이 반영된 계약서를다시 발송드립니다.

상단 차수 문구 – N차(출발 전 확정 안내)

조건 : D-2 발송 대상, 직전 교부상태와 무관하게 차수 +1

문구 : [N차 여행계약서] 출발을 앞두고 확정된 일정이 반영된 계약서입니다. 이후 예약 내용이 변경되는 경우에는변경 사항이 반영된 계약서를 다시 보내드립니다.

상단 차수 문구: 변경 재교부

[N차 여행계약서] 예약 내용이 변경되어 계약서를 다시 보내드립니다.

3
Front 여행경비 5개 항목 [개선 ②]

① 총 N인 경비총액: 예약코드 여행자들의 경비총액 합계

② 1인 여행경비: 조회한 여행자 1인의 경비총액

③ 상품가: 해당 여행자 1인의 판매상품가

④ 유류할증료: 해당 여행자 1인의 QCH

⑤ 개인추가경비: 해당 여행자 1인의 22개 합계(TAX 포함)

② = ③ + ④ + ⑤. 할인·음수 포함

⑤ 대상 0건이면 줄 미노출, 항목 있으면 0원도 표시

4
일정표 선택관광 · 쇼핑 표기 [개선 ③]

일정표에 선택관광·쇼핑을 단순 표기(상세 미표기) — 교통·숙박·식사와 같은 “일정표 표시” 방식

여행계약서 내 '선택관광 / 쇼핑' 필드를 추가 · 닷컴 Vue · 하나허브 OZ Report 모두 반영(공통 VO)

5
약관 동의 영역 (현행 유지)

전체 약관 동의 체크 + 표준/특별약관 동의 라디오 + 개인정보 수집·이용 동의 / 동의는 차수 단위(D-2 갱신 차수 = 최종본 기준)

→ 교부·열람·동의는 구분. 열람 기록·표시 범위는 개발 확인
